3E-Commerce Features

  • Product listing and product detail pages.
  • Admin can add and manage products.
  • Admin can add and manage product categories.
  • Admin can add and manage product tags.
  • Customer registration and login.
  • Add to Cart and checkout functionality.

  • Order status will be managed manually by the Admin.
Inventory Clarification: Inventory/stock management is not included. The system will not provide stock quantity tracking such as how many units are remaining.

4Custom Level-Based Commission System

100% Dynamic Level Configuration: The number of commission levels and the commission percentage/value assigned to each level will be manageable from the Admin Panel.
  • Customer joining fee will be dynamic and Admin-controlled. Example: ₹1,500 can be changed by Admin at any time.
  • Admin can define how many levels will receive commission.
  • Admin can define the commission percentage for each level.
  • A customer will receive commission according to the level assigned to that customer.
  • Commission will be calculated on the applicable particular sale value.
  • For every applicable sale, the configured commission will be credited to the respective customer's wallet.
  • The complete level-wise commission configuration will remain dynamic through the Admin Panel.

5Customer Panel & Wallet
